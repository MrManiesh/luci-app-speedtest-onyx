# Release v1.0-r15

## Speedtest Onyx Console for OpenWrt / ImmortalWrt
- **Modern Speedometer Gauge**: High-precision SVG semi-circular gauge with glowing pointer needle and live speed readouts.
- **Real-Time Telemetry Cards**: Live tracking of Ping, Jitter, Download, Upload, and Packet Loss.
- **Compact Live Terminal**: Embedded session streaming console displaying real-time command output.
- **Engine Optimization**: Fully optimized for official Ookla Speedtest CLI with fallback support for speedtest-go.
